# 说人话

把抽象、工程化、AI 味、过度正式或不好理解的内容，改成中文、直接、可执行的人话表达。

## 适用内容

1. 对话解释。
2. PRD 段落。
3. 需求分析结论。
4. 外部确认消息。
5. SOP、AGENTS.md、skill 文档。
6. 评审结论和修改建议。

## 改写规则

1. 不改变业务事实、范围、结论和风险等级。
2. 先说结论，再说原因和下一步。
3. 用短句和具体动作。
4. 少用抽象词；必须使用术语时先解释。
5. 使用项目已有术语，不发明新词。
6. 保留事实、推测、待确认、风险、范围外的边界。
7. 删除空泛套话，例如“赋能”“提升体验”“保障能力”“闭环建设”等没有对象、动作和结果的表达。

## 输出方式

用户只要求“说人话”时，直接给改写版。需要说明时，再补一句“主要改了哪些表达问题”。

不要把正式 PRD 改成闲聊文案；正式文档仍保持可评审、可研发、可测试。
